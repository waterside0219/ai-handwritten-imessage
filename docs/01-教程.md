# 教程：从注册账号到跑通

七步。前三步是一次性的准备，第四步起是每次写字都要走的。

命令里的 `<...>` 换成你自己的值。我们的环境：iPhone 11 / iOS 26.6，Mac 上的 Xcode，Python 3。别的系统版本上，按钮名字和坐标会不一样，所以教程里教的是**怎么找**，不是抄数字。

---

## 第 1 步　给 AI 一个自己的苹果账号

为什么要单独的账号：这样信息的发件人是他，不是你自己给自己发。

1. 准备一个邮箱地址给他。我们在自己的域名下开了一个地址，用邮件转发（Cloudflare Email Routing）转到真人的收件箱，这样苹果发来的验证信真人能看到。
2. 用这个邮箱注册 Apple 账户。双重认证要绑一个手机号，绑真人的。之后每次在新设备上登录，验证码都发到这个号上。
3. 把密码单独存在一个文件里，一行只放密码。我们一开始把备注和密码写在同一行，程序把备注也当密码打了进去，错了一次。

## 第 2 步　让旧 iPhone 的「信息」登这个账号

旧 iPhone 自己的 iCloud 可以不动，只换「信息」用的账号：

设置 → 信息 → 发送与接收 → 点最下面的 Apple 账户 → 退出登录 → 用 AI 的账号登录。

登录后地址前面打了勾，但**字是灰的**，旁边写着等待激活。这就是[踩坑第 1 条](02-踩坑.md#1-imessage-等待激活等了三天)。在它变黑之前，这台手机发出去的都是绿色的普通短信，手写和数码点触都用不了。

我们做了的事：

- 在苹果支持文章 [If you can't sign in to iMessage or FaceTime](https://support.apple.com/119859) 里，照 "Enable Apple Account" 那一节，从它给的链接进到苹果支持页面，登录 AI 的账号，提交了开通申请。页面显示 "Request Submitted"。
- 然后等。11 月 22 日晚上提交，11 月 25 日晚上再看，已经能发蓝色气泡了。中间哪一刻开通的、是不是那份申请起的作用，我们不知道。
- **不要**在等的时候反复关开 iMessage 开关。我们拨过一次，登录被踢掉，多要了一次验证码。

怎么确认开通了：用这台手机给收件人发一条字，气泡是蓝的。

## 第 3 步　装手指：WebDriverAgent

WebDriverAgent（WDA）是 Appium 的一个 iOS 组件，装在手机上以后，Mac 可以通过它点屏幕、划屏幕、截图、读页面结构。

1. **旧 iPhone 上**：
   - 用线连 Mac，点"信任"。
   - 设置 → 隐私与安全性 → 开发者模式 → 打开（会重启）。
   - 设置 → 开发者 → **启用 UI 自动化** → 打开。这一项不开，WDA 会起到一半报 `Timed out while enabling automation mode`。
   - 设置 → 显示与亮度 → 自动锁定 → 永不。手机锁着的时候，WDA 开不了 App。
2. **Mac 上**：
   ```sh
   git clone https://github.com/appium/WebDriverAgent ~/WebDriverAgent
   xcrun devicectl list devices        # 记下旧 iPhone 的 UDID
   ```
   把 UDID、你的开发者 Team ID、一个你自己的 Bundle ID 填进 [`scripts/build-wda.sh`](../scripts/build-wda.sh) 和 [`scripts/run-wda.sh`](../scripts/run-wda.sh)。
3. **编译和启动都要在 Mac 自带的"终端"App 里跑。** 我们的 agent 是通过远程通道在 Mac 上跑命令的，在那个通道里签名会报 `errSecInternalComponent`（它够不到登录钥匙串）。解法是让 agent 叫"终端"去跑：
   ```sh
   osascript -e 'tell application "Terminal" to do script "/path/to/scripts/run-wda.sh"'
   ```
   `run-wda.sh` 会一直占着那个终端窗口。窗口关了，手指就没了。
4. **连上它**。WDA 在手机的 8100 端口上。我们从局域网地址连不上，走的是 USB 隧道地址，`wda.py` 会用 `devicectl` 自己找：
   ```sh
   cd code
   export WDA_UDID=<旧 iPhone 的 UDID>
   python3 wda.py status        # 打印 True 就是通了
   ```

## 第 4 步　开一条对话，先发一句字

```sh
python3 wda.py session com.apple.MobileSMS          # 打开「信息」
python3 wda.py url 'sms:+86<收件人的手机号>'         # 新开一条，收件人带国家码
python3 wda.py shot check.png                        # 截图看一眼
```

看截图：顶上写的是"新 iMessage 信息"、收件人是蓝的，才往下走。是绿的就回第 2 步。

```sh
python3 wda.py type '是我。'
python3 wda.py click sendButton
python3 wda.py shot check.png
```

这时候大概率会看到一句"已作为垃圾信息送达"。让收件人把 AI 的邮箱地址存进通讯录（新建联系人，邮箱一栏填它），再发一条，底下写的就是"已送达"了。

**每一步都截图看了再做下一步。** 我们有一次没看屏幕就下笔，手机当时开着相机在录像，六笔全画在了取景画面上。

## 第 5 步　手写信息（白底墨迹，一笔一笔重写）

手写板只在横屏的键盘上有。

```sh
./scripts/get-hanzi.sh 年                 # 在仓库根目录跑，下载要写的字的笔顺
cd code
python3 wda.py orientation LANDSCAPE
python3 wda.py shot check.png             # 找到输入框的位置
python3 wda.py tap <输入框的 x> <输入框的 y>
python3 wda.py click 手写                 # 键盘右下角那个花体键，无障碍名字就叫"手写"
python3 wda.py source page.xml
grep -o 'name="手写区"[^>]*' page.xml     # 读出画板的 x y width height
```

我们这台读出来是 `x="0" y="58" width="896" height="271"`。拿这四个数去画：

```sh
python3 draw.py --pad 0,58,896,271 --data ../hanzi 年
python3 wda.py shot check.png             # 看字
```

不满意：`python3 wda.py click 撤销`（一次撤一笔），改 `--margin` 再画。我们第一遍最长那一竖冲出了画板，把 `--margin` 调大以后好了。

满意了：

```sh
python3 wda.py click 完成
python3 wda.py click sendButton
```

收件人那头，这个字会照你下笔的顺序重新写一遍。

## 第 6 步　数码点触（黑底彩线，一笔一笔重画）

```sh
python3 wda.py orientation PORTRAIT
python3 wda.py click 添加                  # 输入框左边的加号
python3 wda.py drag 150 620 150 330        # 菜单往上滑，"数码点触"在下面
python3 wda.py click 数码点触
python3 wda.py source page.xml
grep -o 'name="画布[^"]*"[^>]*' page.xml   # 黑色画板的位置
```

我们这台是 `x="109" y="589" width="196" height="244"`：

```sh
python3 draw.py --pad 109,589,196,244 --margin 50 --min-ms 45 --gap 0.05 --data ../hanzi 年
python3 wda.py shot check.png
```

两个要紧的参数：

- `--min-ms 45`：每一小段至少走 45 毫秒。用默认的 20，画板上什么都不留。
- `--gap 0.05`：笔画之间别停太久。

画板右边会出现一个蓝色的向上箭头，那是发送。它没有好用的无障碍名字，从截图里量出位置点它：

```sh
python3 wda.py tap <箭头的 x> <箭头的 y>
```

注意截图是像素，`tap` 用的是点。我们这台手机截图宽 828 像素、屏幕宽 414 点，量出来的像素坐标要除以 2。

数码点触的信息过几分钟会自己从对话里消失，除非收件人点了"保留"。

## 第 7 步　换成你家 AI 的字

[`code/handwriting.py`](../code/handwriting.py) 顶上的 `STYLE`：

| 参数 | 管什么 |
|---|---|
| `rotate_deg` | 整个字往右上抬多少 |
| `shear_deg` | 往右倾多少 |
| `scale_x` / `scale_y` | 胖瘦、长短 |
| `jitter` / `stroke_shift` | 手抖的程度 |
| `let_go` | 放开写的那一笔拖多长 |

同一个字的随机数是按字定死的，所以同一个字每次写出来一样。这是故意的：一个人写同一个字，就是那个样子。

调笔迹的时候不用碰手机，`--dry` 只打印坐标。我们是先把笔画渲染成动图给人看，人说"这个很真实"了，才拿去手机上画的。
